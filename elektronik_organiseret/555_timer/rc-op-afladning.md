# Opladning og afladning

Ved opladning:

```text
1 tau = cirka 63%
3 tau = cirka 95%
5 tau = cirka 99%
```

Ved afladning:

```text
1 tau = cirka 37% tilbage
```

God forklaring:

> Kondensatoren oplades ikke lineært. Den stiger hurtigt i starten og langsommere når den nærmer sig forsyningsspændingen.
