# MQ-135 & MQ-2 - Gassensorer

## Beskrivelse
MQ-serien af gassensorer anvender et varmelegeme (heater) og et halvlederlag af tindioxid ($\text{SnO}_2$). Når sensoren varmes op, reagerer gassen med oxygenet på halvlederens overflade, hvilket ændrer modstanden i sensoren ($R_s$). Modstanden falder, jo højere gaskoncentrationen er, hvilket resulterer i en højere udgangsspænding.

- **MQ-135**: Bruges til luftkvalitet (ammoniak, $\text{CO}_2$, benzen, alkohol, røg).
- **MQ-2**: Bruges til brændbare gasser (LPG, propan, metan, brint, røg).

### Opvarmningsfase (Heater)
Fordi sensoren bygger på en kemisk opvarmningsproces, **skal** den varme op før måling.
- **Indbrænding**: Nye sensorer skal køre konstant i 24-48 timer før kalibrering.
- **Warm-up**: Ved hver opstart skal sensoren køre i **mindst 2 minutter** (30 sekunder som absolut minimum) før målinger tages. Den bliver fysisk lun.

### Ledningsforbindelse (Wiring):
- **VCC**: **5V** (Sensorens varmelegeme kræver 5V for at nå den rette arbejdstemperatur).
- **GND**: GND (Fælles stel med ESP32).
- **AOUT (Analog Out)**: Forbindes til en analog indgang (fx GPIO 33 på ESP32). *Bemærk: Hvis sensoren kører på 5V, kan AOUT teoretisk give 5V. På mange breakout-boards er spændingen dog lavere under normale forhold, men for fuld sikkerhed kan der bruges en spændingsdeler til at bringe signalet ned til ESP32'erens 3.3V grænse.*
- **DOUT (Digital Out)**: Valgfri digital pin. Går HIGH/LOW baseret på en threshold sat via potentiometret på bagsiden af modulet.

## Kodeeksempel (PlatformIO / Arduino C++)
Eksemplet viser, hvordan man udfører en simpel kalibrering for at finde reference-modstanden ($R_0$) i ren luft og derefter beregne gaskoncentrations-forholdet ($R_s/R_0$):

```cpp
#include <Arduino.h>

const int gasPin = 33;       // AOUT på GPIO33 (ADC1)
const float V_CC = 3.3;      // ESP32 reference spænding
const float R_L = 10.0;      // Belastningsmodstand (load resistor) på boardet i kOhm
float R0 = 10.0;             // Standardværdi for R0 (kalibreres i setup)

// Kalibreringsfunktion i ren luft
float calibrateR0() {
    float sumRs = 0;
    int samples = 50;

    Serial.println("Kalibrerer R0 i ren luft... Hold sensoren væk fra gas.");
    for (int i = 0; i < samples; i++) {
        int raw = analogRead(gasPin);
        float V_out = (raw / 4095.0) * V_CC;
        
        // Forebyg division med nul
        if (V_out < 0.1) V_out = 0.1; 
        
        // Beregn Rs: Rs = ((Vcc - Vout) / Vout) * RL
        float Rs = ((V_CC - V_out) / V_out) * R_L;
        sumRs += Rs;
        delay(100);
    }
    
    float averageRs = sumRs / samples;
    // For MQ-135 i ren luft er Rs/R0 forholdet ca. 3.6 (se datablad)
    float calibratedR0 = averageRs / 3.6; 
    return calibratedR0;
}

void setup() {
    Serial.begin(115200);
    pinMode(gasPin, INPUT);

    Serial.println("Varmer sensor op (heater)... Vent 30 sekunder.");
    delay(30000); // 30 sekunders opvarmning (brug 2 min i virkeligheden)

    R0 = calibrateR0();
    Serial.print("Kalibrering færdig! R0 sat til: ");
    Serial.print(R0);
    Serial.println(" kOhm");
}

void loop() {
    int raw = analogRead(gasPin);
    float V_out = (raw / 4095.0) * V_CC;
    
    if (V_out < 0.1) V_out = 0.1;
    
    // Beregn den aktuelle Rs under drift
    float Rs = ((V_CC - V_out) / V_out) * R_L;
    float ratio = Rs / R0; // Rs/R0 forholdet

    Serial.print("Rå ADC: ");
    Serial.print(raw);
    Serial.print("  |  Spænding: ");
    Serial.print(V_out);
    Serial.print(" V  |  Rs/R0 Ratio: ");
    Serial.println(ratio);

    // Simple thresholds baseret på rå værdier
    if (raw < 200) {
        Serial.println("Luftstatus: Fremragende");
    } else if (raw >= 200 && raw <= 400) {
        Serial.println("Luftstatus: Moderat gas fundet");
    } else {
        Serial.println("Luftstatus: ADVARSEL - Høj gaskoncentration!");
    }

    delay(2000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Hvorfor viser værdierne støj i starten?**: Hvis varmelegemet (heateren) ikke er varmt nok, vil modstanden svinge voldsomt. Sørg for at lade sensoren varme op.
- **Hvorfor skal VCC have 5V, når ESP32 kører på 3.3V?**: Varmelegemet i MQ-sensorerne trækker meget strøm og kræver 5V for at nå den kemiske arbejdstemperatur. Hvis du forbinder varmelegemet til 3.3V, vil sensoren aldrig blive varm nok, og målingerne bliver ubrugelige.
- **Hvad er formålet med R0?**: Fordi halvledersensorer varierer fra fabrikken og ændres med fugtighed/alder, kan man ikke bruge absolutte modstandsværdier. Vi måler derfor forholdet $\frac{R_s}{R_0}$, som fortæller os, hvor meget modstanden er faldet i forhold til ren luft.
