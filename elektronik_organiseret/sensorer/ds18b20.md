# DS18B20 - Digital Temperatur-sensor (OneWire)

## Beskrivelse
DS18B20 er en populær digital temperatursensor, der kommunikerer over Dallas/Maxim **1-Wire** bussen. Det unikke ved 1-Wire protokollen er, at mange sensorer kan dele den samme data-ledning, da hver sensor har en unik indbygget 64-bit hardware-adresse.

### Egenskaber:
- **Signal**: OneWire digital protokol.
- **Adresse**: Unik 64-bit adresse pr. sensor (muliggør mange sensorer på én pin).
- **Præcision**: Meget høj præcision ($\pm 0.5^\circ\text{C}$ over området $-10^\circ\text{C}$ til $+85^\circ\text{C}$).

### Den kritiske Pull-up modstand (Eksamen!)
1-Wire bussen bruger "open-drain" udgange. Derfor **skal** der forbindes en **$4.7\text{ k}\Omega$ pull-up modstand** (nogle gange kan en 10k modstand bruges til korte afstande) mellem `DATA` ledningen og `VCC (3.3V)`. Uden denne modstand vil ESP32 aldrig kunne modtage data, og sensoren vil typisk returnere temperaturen `-127`.

### Ledningsforbindelse (Wiring):
- **VCC**: 3.3V (eller 5V)
- **GND**: GND (Fælles stel)
- **DATA**: GPIO pin (fx GPIO 19) + **$4.7\text{ k}\Omega$ modstand forbundet til 3.3V**.

## Kodeeksempel (PlatformIO / Arduino C++)
Kræver `OneWire` og `DallasTemperature` i `platformio.ini`:
```ini
lib_deps =
    paulstoffregen/OneWire @ ^2.3.8
    milesburton/DallasTemperature @ ^3.9.0
```

```cpp
#include <Arduino.h>
#include <OneWire.h>
#include <DallasTemperature.h>

#define ONE_WIRE_BUS 19 // GPIO pin tilsluttet data-linjen

OneWire oneWire(ONE_WIRE_BUS);
DallasTemperature sensors(&oneWire);

void setup() {
    Serial.begin(115200);
    sensors.begin(); // Start Dallas library
    
    // Tjek om der overhovedet er sensorer tilsluttet
    Serial.print("Fandt ");
    Serial.print(sensors.getDeviceCount(), DEC);
    Serial.println(" sensor(er) på bussen.");
}

void loop() {
    Serial.print("Anmoder om temperaturer...");
    sensors.requestTemperatures(); // Send kommando om at måle
    Serial.println(" Færdig.");

    // Hent temperaturen for den første sensor (index 0)
    float tempC = sensors.getTempCByIndex(0);

    // Tjek om målingen lykkedes
    if (tempC == DEVICE_DISCONNECTED_C) {
        Serial.println("Fejl: Kunne ikke læse data! Tjek 4.7k pull-up modstand.");
    } else {
        Serial.print("Temperatur: ");
        Serial.print(tempC);
        Serial.println(" C");
    }

    delay(2000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Målingen viser `-127.00`**: Dette er den mest almindelige OneWire fejl. Det betyder, at sensoren ikke svarer på bussen. Årsagen er næsten altid en manglende eller forkert forbundet $4.7\text{ k}\Omega$ pull-up modstand, eller at sensoren mangler strøm/GND.
- **Målingen viser `85.00`**: Dette er sensorens interne default-værdi ved opstart (power-on reset value). Hvis du læser værdien med det samme uden at køre `requestTemperatures()` først, eller hvis sensoren genstarter uønsket midt i loopet pga. støj/spændingsfald, får du værdien 85.
- **Hvad betyder "Parasite Power"?**: DS18B20 understøtter en tilstand, hvor den kan trække strøm direkte fra data-ledningen (så man kun behøver 2 ledninger: DATA og GND). Det kræver dog speciel softwarestyring og en stærk pull-up, så det anbefales normalt at forbinde den med alle 3 ledninger (VCC, GND, DATA).
