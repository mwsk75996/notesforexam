# ADS1115 - Ekstern 16-bit ADC (Analog-to-Digital Converter)

## Beskrivelse
ADS1115 er en præcis ekstern ADC med 16-bit opløsning, som kommunikerer med ESP32 via I2C. 
- **Opløsning**: 16-bit ($2^{16} = 65536$ niveauer), hvilket er langt mere præcist end ESP32'erens indbyggede 12-bit ADC ($2^{12} = 4096$ niveauer).
- **Stabilitet**: Har en indbygget intern spændingsreference, som gør målingerne meget stabile og støjfri sammenlignet med ESP32 ADC.
- **Kanaler**: Har 4 analoge indgange (A0-A3), der kan bruges til enkelte målinger (single-ended) eller som 2 differentielle målinger (måle spændingsforskellen mellem to pins, fx i en Wheatstonebro).

### Ledningsforbindelse (I2C Wiring):
- **VCC**: 3.3V (eller 5V)
- **GND**: GND (Fælles stel)
- **SDA**: GPIO 21 (ESP32 standard SDA)
- **SCL**: GPIO 22 (ESP32 standard SCL)
- **ADDR**: Forbindes til GND for I2C-adresse `0x48` (standard).

## Kodeeksempel (PlatformIO / Arduino C++)
Kræver `Adafruit ADS1X15` i `platformio.ini`:
```ini
lib_deps =
    adafruit/Adafruit ADS1X15 @ ^2.5.0
```

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_ADS1X15.h>

Adafruit_ADS1115 ads; // Opret et ADS1115 objekt (16-bit version)

void setup() {
    Serial.begin(115200);
    Serial.println("Initialiserer ADS1115...");

    // Start ADS1115 (standard I2C adresse er 0x48)
    if (!ads.begin(0x48)) {
        Serial.println("Kunne ikke finde ADS1115 chip! Tjek ledninger.");
        while (1);
    }

    // Indstil forstærkning (Gain) - bestemmer spændingsområdet
    // ADS1X15_REG_CONFIG_PGA_6_144V: Range = +-6.144V (1 bit = 0.1875mV)
    // ADS1X15_REG_CONFIG_PGA_4_096V: Range = +-4.096V (1 bit = 0.125mV)
    // ADS1X15_REG_CONFIG_PGA_2_048V: Range = +-2.048V (1 bit = 0.0625mV) - standard
    ads.setGain(GAIN_TWOTHIRDS); // +-6.144V range (sikker hvis vi måler op til 5V)

    Serial.println("ADS1115 klar!");
}

void loop() {
    int16_t adc0;
    float volts0;

    // Læs rå værdi fra kanal A0 (single-ended)
    adc0 = ads.readADC_SingleEnded(0);
    
    // Omregn den rå værdi til spænding i Volt
    // computeVolts tager højde for den aktuelle Gain-indstilling
    volts0 = ads.computeVolts(adc0); 

    Serial.print("Kanal A0 rå værdi: ");
    Serial.print(adc0);
    Serial.print("  |  Spænding: ");
    Serial.print(volts0, 4); // Vis med 4 decimalers præcision
    Serial.println(" V");

    delay(1000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Hvorfor bruge en ekstern ADC i stedet for ESP32'erens egen?**:
  1. **Linearitet**: ESP32'erens indbyggede ADC er berygtet for at være ulineær (især tæt på 0V og 3.3V). ADS1115 er ekstremt lineær.
  2. **Præcision**: ADS1115 har 16-bit opløsning (hvoraf 15 bit bruges til positive spændinger ved single-ended), hvilket giver over 32.000 niveauer, mod ESP32'erens 4096 niveauer.
  3. **Støj**: ESP32'erens ADC støjer meget pga. interne WiFi-signaler på chippen. ADS1115 er fuldstændig afkoblet elektrisk.
- **Hvad sker der, hvis input-spændingen overskrider VCC?**: Spændingen på de analoge indgange må aldrig overstige $V_{CC} + 0.3\text{V}$. Selvom du indstiller gain til $\pm 6.144\text{V}$, må du ikke sende $5\text{V}$ ind på sensoren, hvis den kun forsynes med $3.3\text{V}$!
