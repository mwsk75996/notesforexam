# HMC5883L / QMC5883L - Digitalt Kompas (Magnetometer)

## Beskrivelse
Et tre-akset digitalt kompas (magnetometer) måler jordens magnetfelt i X, Y og Z akserne. Ud fra de magnetiske målinger kan vi beregne sensorens aktuelle kompasretning (heading/vinkel i forhold til magnetisk nord).

### Eksamensfælde: HMC5883L vs. QMC5883L (Kloner)
Mange af de billige moduler, man køber som "GY-271 HMC5883L", indeholder i virkeligheden en kinesisk klon kaldet **QMC5883L**. Disse to chips er **ikke** kompatible:
- **HMC5883L** (original): Har I2C adresse **`0x1E`**. Registersæt er anderledes.
- **QMC5883L** (klon): Har I2C adresse **`0x0D`**. Registersæt er anderledes og kræver et andet bibliotek.
*Hvis din kode kompilerer uden fejl, men kompasset nægter at svare eller fejler ved initialisering, skyldes det næsten altid, at du bruger et HMC-bibliotek på en QMC-chip.*

### Ledningsforbindelse (I2C Wiring):
- **VCC**: 3.3V
- **GND**: GND (Fælles stel)
- **SDA**: GPIO 21 (ESP32 standard SDA)
- **SCL**: GPIO 22 (ESP32 standard SCL)

## Kodeeksempel (PlatformIO / Arduino C++)
Her er koden til den meget udbredte **QMC5883L** (adresse `0x0D`).
Kræver `QMC5883LCompass` i `platformio.ini`:
```ini
lib_deps =
    mprograms/QMC5883LCompass @ ^1.2.3
```

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <QMC5883LCompass.h>

QMC5883LCompass compass;

void setup() {
    Serial.begin(115200);
    Wire.begin(21, 22); // Start I2C med standard SDA=21, SCL=22
    
    compass.init(); // Initialiserer QMC-sensoren (adresse 0x0D)
    Serial.println("QMC5883L kompas klar!");
}

void loop() {
    compass.read(); // Læs magnetfelt værdier

    // Hent de rå magnetiske X, Y, Z værdier
    int x = compass.getX();
    int y = compass.getY();
    int z = compass.getZ();

    // Hent den beregnede retningsvinkel (0-359 grader)
    // 0 = Nord, 90 = Øst, 180 = Syd, 270 = Vest
    int heading = compass.getAzimuth(); 

    Serial.print("Magnetfelt: X=");
    Serial.print(x);
    Serial.print(" Y=");
    Serial.print(y);
    Serial.print(" Z=");
    Serial.print(z);
    
    Serial.print("  |  Retning: ");
    Serial.print(heading);
    Serial.println(" grader");

    delay(1000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Hvorfor viser kompasset helt forkerte værdier?**: Magnetometre er ekstremt følsomme over for magnetisk interferens (jernholdigt metal, skruer, motorer og strømførende ledninger tæt på sensoren). Hvis sensoren er monteret på en rover tæt på motorerne, skal den kalibreres for at fratrække bilens eget magnetfelt (Hard-iron / Soft-iron kalibrering).
- **Hvordan beregnes retningen (azimuth) manuelt?**: Retningen beregnes ud fra X og Y værdierne ved hjælp af trigonometri:
  $$\theta = \text{atan2}(Y, X)$$
  Vinklen omregnes derefter fra radianer til grader, og der justeres for den magnetiske deklination (forskellen på magnetisk nord og geografisk nord på din lokation).
