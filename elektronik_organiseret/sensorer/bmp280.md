# BMP280 - Lufttryk og Temperatur

## Beskrivelse
BMP280 er en højpræcisions digital sensor, der måler atmosfærisk lufttryk og temperatur. Den kommunikerer via I2C eller SPI. Da lufttrykket aftager med højden, bruges barometertrykket ofte til at estimere den aktuelle højde (altitude).

### Egenskaber:
- **Signal**: I2C (standardadresser: `0x76` eller `0x77`) eller SPI.
- **Formål**: Vejrstationer, højdemåling (fx til droner/rovere) og indeklima.
- **Højdestestimering**: Kan beregne højde ud fra trykket set i forhold til trykket ved havoverfladen (standard: $1013.25\text{ hPa}$).

### Typisk ledningsforbindelse (I2C Wiring):
- **VCC**: 3.3V
- **GND**: GND (Fælles stel)
- **SDA**: GPIO 21 (ESP32 standard SDA)
- **SCL**: GPIO 22 (ESP32 standard SCL)

## Kodeeksempel (PlatformIO / Arduino C++)
Kræver Adafruit `Adafruit BMP280 Library` i `platformio.ini`:
```ini
lib_deps =
    adafruit/Adafruit BMP280 Library @ ^2.6.8
    adafruit/Adafruit Unified Sensor @ ^1.1.14
```

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_BMP280.h>

Adafruit_BMP280 bmp; // Anvender hardware I2C (SDA=21, SCL=22)

void setup() {
    Serial.begin(115200);
    Serial.println("Initialiserer BMP280...");

    // Start I2C og BMP280 (adresse 0x76 er mest almindelig for billige moduler)
    if (!bmp.begin(0x76)) {
        Serial.println("Kunne ikke finde BMP280 sensor! Tjek adresse eller ledninger.");
        while (1) delay(10); // Stop kørsel ved fejl
    }

    /* Valgfrie indstillinger til sensoren */
    bmp.setSampling(Adafruit_BMP280::MODE_NORMAL,     /* Operating Mode. */
                    Adafruit_BMP280::SAMPLING_X2,     /* Temp. oversampling */
                    Adafruit_BMP280::SAMPLING_X16,    /* Pressure oversampling */
                    Adafruit_BMP280::FILTER_X16,      /* Filtering. */
                    Adafruit_BMP280::STANDBY_MS_500); /* Standby time. */
                    
    Serial.println("BMP280 klar!");
}

void loop() {
    float temp = bmp.readTemperature();
    float pressure = bmp.readPressure(); // Tryk i Pascal (Pa)
    
    // Beregn højde ud fra antaget havoverfladetryk (1013.25 hPa)
    float altitude = bmp.readAltitude(1013.25); 

    Serial.print("Temperatur: ");
    Serial.print(temp);
    Serial.print(" C  |  ");
    
    Serial.print("Tryk: ");
    Serial.print(pressure / 100.0); // Omregn til hPa (Hektopascal)
    Serial.print(" hPa  |  ");
    
    Serial.print("Estimeret højde: ");
    Serial.print(altitude);
    Serial.println(" m");

    delay(2000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Sensoren findes ikke ved startup**: Tjek om `SDA` og `SCL` ledningerne er byttet rundt. Kontroller også sensoradressen. Nogle BMP280-breakouts har adressen `0x77` i stedet for `0x76` (kan ændres ved at lodde en jumper på printet).
- **Hvordan beregnes højde?**: Barometrisk højdemåling bygger på den barometriske højdeformel. Da tætheden af luft falder med højden, falder trykket også. Det antagede havoverfladetryk (fx 1013.25 hPa) ændrer sig med vejret, så højdemålingen skal kalibreres for præcision.
- **Er temperaturen nøjagtig?**: BMP280-chippen bliver svagt opvarmet af sin egen strøm og omgivelserne. Derfor er den målte temperatur ofte 1-2 grader højere end den faktiske omgivelsestemperatur.
