# GY-521 / MPU6050 - Accelerometer og Gyroskop

## Beskrivelse
GY-521 modulet indeholder en **MPU6050** sensor, som er en 6-akset IMU (Inertial Measurement Unit). Den måler:
- **3-akset accelerometer**: Måler lineær acceleration i X, Y og Z retningerne (inkl. tyngdeaccelerationen $1g \approx 9.81\text{ m/s}^2$).
- **3-akset gyroskop**: Måler rotationshastighed (vinkelhastighed) omkring de tre akser i grader pr. sekund.
- **Indbygget temperatur-sensor**: Bruges primært til at kompensere for sensordrift pga. varme.

Sensoren kommunikerer via I2C.

### Anvendelse:
- Hældningsmåling (tilt)
- Bevægelsesdetektering (fx rover-alarm eller skridttæller)
- Balancestyring (fx selvbalancerende robotter)

### Ledningsforbindelse (I2C Wiring):
- **VCC**: 3.3V (eller 5V, afhængigt af om modulet har en indbygget 3.3V regulator)
- **GND**: GND (Fælles stel)
- **SDA**: GPIO 21 (ESP32 standard SDA)
- **SCL**: GPIO 22 (ESP32 standard SCL)
- *(AD0 kan forbindes til GND for I2C adresse `0x68` (standard) eller VCC for adresse `0x69`)*

## Kodeeksempel (PlatformIO / Arduino C++)
Kræver `Adafruit MPU6050` i `platformio.ini`:
```ini
lib_deps =
    adafruit/Adafruit MPU6050 @ ^2.2.6
    adafruit/Adafruit Unified Sensor @ ^1.1.14
```

```cpp
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>

Adafruit_MPU6050 mpu;

void setup() {
    Serial.begin(115200);
    Serial.println("Initialiserer MPU6050...");

    // Start MPU6050 over I2C
    if (!mpu.begin()) {
        Serial.println("Kunne ikke finde en MPU6050 chip! Tjek forbindelser.");
        while (1) {
            delay(10);
        }
    }
    Serial.println("MPU6050 klar!");

    // Konfigurer sensorområder (områder kan justeres efter behov)
    mpu.setAccelerometerRange(MPU6050_RANGE_8_G);   // +-8G
    mpu.setGyroRange(MPU6050_RANGE_500_DEG);        // +-500 grader/sek
    mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);     // Digitalt low-pass filter
}

void loop() {
    // Hent sensorbegivenheder
    sensors_event_t a, g, temp;
    mpu.getEvent(&a, &g, &temp);

    // Udskriv accelerometer data (m/s^2)
    Serial.print("Acceleration X: ");
    Serial.print(a.acceleration.x);
    Serial.print(", Y: ");
    Serial.print(a.acceleration.y);
    Serial.print(", Z: ");
    Serial.print(a.acceleration.z);
    Serial.println(" m/s^2");

    // Udskriv gyroskop data (rad/s)
    Serial.print("Rotation X: ");
    Serial.print(g.gyro.x);
    Serial.print(", Y: ");
    Serial.print(g.gyro.y);
    Serial.print(", Z: ");
    Serial.print(g.gyro.z);
    Serial.println(" rad/s");

    // Hvis sensoren ligger stille på bordet, bør Z-accelerationen være ca. 9.8 m/s^2 (tyngdekraften)
    
    Serial.println("------------------------------------");
    delay(1000);
}
```

## Typiske fejl og eksamensspørgsmål
- **Hvorfor driver (drifter) vinklen over tid?**: Hvis du integrerer gyroskopets målinger for at finde en vinkel (vinkel = $\int \text{gyro} \, dt$), vil små støj-målefejl akkumulere over tid. Det kaldes "gyro drift".
- **Hvad er løsningen på gyro drift?**: Man laver **sensor-fusion**. Man kombinerer accelerometeret (som fortæller, hvor tyngdekraften peger nedad på lang sigt, men støjer ved vibrationer) med gyroskopet (som er præcist på kort sigt). Dette gøres ved hjælp af et **komplementær-filter** eller et **Kalman-filter**.
- **Hvad måler accelerometeret, når sensoren ligger helt stille?**: Den måler tyngdeaccelerationen $1g \approx 9.81\text{ m/s}^2$ i Z-retningen (hvis sensoren ligger fladt). Hvis du tipper sensoren, flytter denne kraft sig over på X- og Y-akserne, hvilket kan bruges til at beregne statisk tilt (hældning).
