# Binær til decimal

Binær er base 2. Hver plads er en potens af 2.

```text
128 64 32 16 8 4 2 1
```

Eksempel:

```text
10000010
= 128 + 2
= 130
```

Eksempel:

```text
1100100
= 64 + 32 + 4
= 100
```


## Decimal til binær

Find hvilke 2-potenser der kan lægges sammen.

Eksempel:

```text
35 = 32 + 2 + 1
35 = 100011
```

Eksempel:

```text
170 = 128 + 32 + 8 + 2
170 = 10101010
```

Eksempel:

```text
200 = 128 + 64 + 8
200 = 11001000
```
